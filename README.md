# Zainab Khawar — Portfolio

A responsive, dependency-free portfolio website built with semantic HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. No build step or package installation is required.

## Update portfolio content

The editable portfolio content is grouped in the `portfolio` object at the top of `app.js`: highlights, profile details, skill groups, experience, projects and certifications. Project links are optional. Add `githubUrl`, `liveDemoUrl` or `caseStudyUrl` to a project entry when a real destination is ready; unavailable links stay hidden.

The final-year project has a details disclosure for future screenshots and documentation. Replace the illustrative dashboard with real project media when available. `case-study-template.html` provides an unindexed page structure for adding verified case-study details later.

## CV

`cv.html` is a downloadable, printable CV assembled from the supplied profile details. Its **Print / Save as PDF** control uses the browser print dialog.

## Contact form

The validated contact form opens the visitor’s email application with the message addressed to Zainab. It does not send data to a server.

## Hosting

All files are static and can be deployed to any static web host. The selected Inter and DM Mono fonts load from Google Fonts with system font fallbacks.
